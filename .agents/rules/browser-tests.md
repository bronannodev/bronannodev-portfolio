# Regla: Confirmacion Obligatoria para Pruebas en Navegador

- SIEMPRE solicitar confirmacion previa al usuario antes de ejecutar cualquier prueba automatica en el navegador (incluyendo el uso de `browser_subagent`).
- No ejecutar de forma automatica ninguna accion que abra o controle el navegador web sin consentimiento previo explicito.
- Mantener la regla de no usar emojis en textos, mensajes o interfaz.
